# SHOPX — فروشگاه کامل PHP + MySQL

## نصب
1. پوشه را داخل `htdocs` یا `public_html` قرار دهید.
2. یک دیتابیس MySQL بسازید.
3. `config.php` را با اطلاعات دیتابیس تنظیم کنید، یا `install.php` را اجرا کنید.
4. بعد از نصب، حتماً `install.php` را حذف کنید.
5. برای مدیریت از `/admin/` وارد شوید.

## امکانات
ثبت‌نام/ورود امن، نقش‌های customer/admin/superadmin، فروشگاه، جستجو، دسته‌بندی، مرتب‌سازی، محصول، سبد خرید، ثبت سفارش، تخفیف، تاریخچه سفارش، داشبورد مدیریت، CRUD محصول و دسته‌بندی، مدیریت سفارش، مدیریت کاربر، کد تخفیف و تنظیمات.

## نکته امنیتی
برای محیط واقعی، HTTPS، محدودیت آپلود، درگاه پرداخت واقعی، rate limit و تنظیمات سرور را نیز فعال کنید.
